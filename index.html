Del dato a la decisión

El servicio transforma los datos de una póliza en una señal clara para el equipo de evaluación.

01 / ENTRADA

Recibir

Validamos póliza, monto, antigüedad y siniestros previos antes de procesar la solicitud.

02 / MODELO

Evaluar

El predictor local calcula una probabilidad entre 0 y 1 usando los rasgos de la póliza.

03 / SALIDA

Responder

Devolvemos el puntaje, la clasificación de riesgo y un registro de la evaluación.

Mapa del servicio

Rutas disponibles para operación, consulta y diagnóstico de carga.

POST

/score

Puntúa una póliza y devuelve el riesgo estimado.

GET

/historial

Consulta las evaluaciones realizadas durante la ejecución.

GET

/siniestros/{id}

Busca un siniestro en el archivo de datos.

GET

/exportar

Entrega el histórico en JSON para actuaría.

GET

/health

Confirma que el servicio está operativo.

GET

/ping

Comprobación rápida de disponibilidad.

GET

/consulta-archivo

Mide la lectura del archivo de siniestros.

GET

/servicio-externo

Simula una espera de servicio externo.

GET

/calculo-pesado

Mide el comportamiento de una operación intensiva en CPU.

Contrato de respuesta

Las respuestas están diseñadas para ser previsibles tanto para usuarios como para otros servicios.

200 · Correcto

La solicitud fue procesada y devuelve JSON estructurado.

422 · Entrada inválida

Falta un campo o no cumple las restricciones declaradas.

404 · No encontrado

El identificador consultado no existe en los datos.
